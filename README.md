# BidCraft

Una app de presupuestos que evolucionamos paso a paso en RefactorIA: desde el trabajo en vivo hasta un producto preparado para múltiples usuarios concurrentes.

El proyecto muestra cómo Juan revisa una aplicación real, pide pruebas, interpreta resultados, decide cambios y verifica despliegues. No es una garantía de capacidad ni una declaración de que ya esté listo para producción.

## Por dónde empezar

1. [Contexto y recorrido didáctico](docs/corrida-didactica/README.md): destino del proyecto, forma de trabajo y evidencia esperada.
2. [Roadmap de la corrida](odd/tasks/roadmap-corrida-didactica.md): hitos, alcance aprobado y registros históricos.
3. [Etapas](docs/corrida-didactica/etapas.md): medir, corregir con fundamento y verificar el despliegue.

## Estado y antecedentes

El repositorio contiene código y registros de pruebas y despliegues. Esos registros describen versiones y entornos concretos; no certifican el estado actual ni la capacidad general para múltiples usuarios.

La implementación nació como participante Nan de un ejercicio de presupuestos. Los insumos históricos se conservan en `.ai/`, incluida `.ai/KICKSTART.md`. Ese borrador no describe por sí solo el estado actual de BidCraft ni reemplaza el recorrido didáctico.
