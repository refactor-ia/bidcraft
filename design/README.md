# Origen del material de presentación

Esta copia conserva las diapositivas, el guion de conducción y los archivos fuente usados para el recorrido de BidCraft, junto con el snapshot del design system de RefactorIA que permite regenerarlos.

- Origen: https://github.com/refactor-ia/refactoria
- Diapositivas y uso: [saas-chico-grandecito/README.md](saas-chico-grandecito/README.md).
- Tokens y documentación visual: [refactoria-design-system/README.md](refactoria-design-system/README.md), `tokens.json`, `tokens.css` y `SYNC.md`.
- Contexto del proyecto: [recorrido didáctico](../docs/corrida-didactica/README.md).

Se conservan las rutas relativas para que las fuentes, el logo y las texturas sigan disponibles al regenerar. Desde la raíz del repositorio: `python3 design/saas-chico-grandecito/build.py`.

El guion es para conducir la presentación, no para capturarlo en OBS; está publicado como material del proyecto. Las notas y verificaciones originales son históricas, no una comprobación del estado actual de BidCraft. La vista de presentador sigue pendiente de prueba interactiva según el README original.

El design system general y la metodología reutilizable siguen perteneciendo a RefactorIA. Esta es una copia de referencia, no una nueva fuente de verdad de la marca ni una sincronización automática. No se encontró un informe separado de investigación de tokens: se incluyen los tokens, la documentación y los componentes presentes en el snapshot.
