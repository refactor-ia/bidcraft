The RefactorIA marks. Sources: the brand Drive folder.

- `refactoria-mark-light.svg`: the full beard in solid silhouette (upswept sides, moustache set into the beard), ink `light-300` (#f2effa) on a transparent ground. Default on dark grounds.
- `refactoria-mark-dark.svg`: the same, ink `dark-900` (#0b0714). For light grounds.
- `refactoria-mark-tile.svg`: the beard centred on a `dark-900` square. Avatars and app icons; the favicon set is rendered from it.
- `refactoria-wordmark.png`: the name set as "Refactor" in white and "IA" in `brand-500`, on a transparent ground. For dark grounds only.
- `refactoria-mark-master.png`: the 1254×1254 master raster (`RefactorIA-Front.png`) the SVGs were traced from with potrace. Keep it for re-tracing; don't use it in layouts.
- `refactoria-braille.txt`: the beard rendered in braille (U+2800 block), 56 columns × 36 rows. The hero uses it as text in the mono family.
