# MotionStates

Reference for hover, press, focus and confirm states in the electric-with-glow character; not a component to import.

Shows a primary button, a content card and a mono accent wired to `glow-sm`, `glow-md`, `glow-press`, `text-glow-strong`, `lift-sm`, `lift-md`, `press-scale`, `duration-hover`, `duration-card`, `duration-press` and `ease-out-expo`. The rules live in the README's Motion section.
